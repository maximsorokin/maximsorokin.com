# maximsorokin.com

Личная страница-визитка Максима Сорокина. Один экран, английский язык, два состояния:
десктоп (≥ 768px) и мобильный (< 768px).

## Что внутри

```
index.html    вся разметка и тексты
styles.css    стили: мобильный базовый, один медиазапрос на 768px
fonts/        Inter 400/500/700, woff2, латинский субсет
og.jpg        картинка для превью ссылки (1200×630)
robots.txt
```

## Стек

Чистый HTML и CSS. Ни фреймворков, ни сборщиков, ни npm, ни JavaScript
(единственный `<script>` — JSON-LD `Person`, это данные, а не код).
Inter подключён локально: внешний запрос к CDN задерживает первую отрисовку
и тянет за собой стороннего провайдера.

Правка текста — одна строка в `index.html`, пересобирать нечего.
Неразрывных пробелов в разметке нет: правило «`&nbsp;` после предлогов и союзов»
относится к русской типографике, к английской не применяется.

## Локальный просмотр

Достаточно открыть `index.html` в браузере. Либо, чтобы пути вели себя
как на проде:

```bash
python3 -m http.server 8000
```

## Деплой

Хостинг — reg.ru, панель ispmanager. Сборки нет: что лежит в репозитории, то
и заливается в корень сайта по SFTP или через файловый менеджер ispmanager.

Домен `maximsorokin.com` уже привязан и резолвится на `2a00:f940:2:2:1:1:0:260`.
DNS не трогаем — на домене живёт почта `mail@maximsorokin.com`, MX-записи задевать нельзя.
GitHub Pages не используется, `CNAME` поэтому удалён.

После заливки проверить HTTPS и редиректы с `http://` и с `www.`
