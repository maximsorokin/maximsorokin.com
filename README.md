# maximsorokin.com

Личная страница-визитка Максима Сорокина. Один экран, английский язык, два состояния:
десктоп (≥ 768px) и мобильный (< 768px).

## Что внутри

```
index.html    вся разметка и тексты
styles.css    стили: мобильный базовый, один медиазапрос на 768px
fonts/        Inter 400/500/700, woff2, латинский субсет
og.jpg        картинка для превью ссылки (1200×630)
robots.txt
src/og.html   исходник og.jpg, на хостинг не заливается
```

Комментарии в `styles.css` — по-английски: файл отдаётся браузеру по адресу
`maximsorokin.com/styles.css` вместе со страницей, и открывают его ровно те,
кто заметит там русский текст. В README и в `src/` — по-русски, наружу они
не попадают.

## Стек

Чистый HTML и CSS. Ни фреймворков, ни сборщиков, ни npm, ни JavaScript
(единственный `<script>` — JSON-LD `Person`, это данные, а не код).
Inter подключён локально: внешний запрос к CDN задерживает первую отрисовку
и тянет за собой стороннего провайдера.

Правка текста — одна строка в `index.html`, пересобирать нечего.

Русское правило «`&nbsp;` после всех предлогов и союзов» к английскому тексту
не применяется, но два приёма в разметке есть:

- `&nbsp;` после `at`, `on` и `and` — короткое служебное слово не остаётся
  висеть в конце строки;
- `.nowrap` на `alfa-bank`, `rambler/kassa` и `rambler/mail` — дефис и слэш
  для браузера точки переноса, и название рвалось пополам.

## og-картинка

`og.jpg` — не фотография, а свёрстанная страница `src/og.html`, снятая
скриншотом. Меняется должность или компания — правится текст в исходнике
и картинка пересобирается двумя командами из корня репозитория:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
	--headless=new --disable-gpu --hide-scrollbars \
	--force-device-scale-factor=1 --allow-file-access-from-files \
	--screenshot=src/og.png --window-size=1200,630 "file://$PWD/src/og.html"

sips -s format jpeg -s formatOptions 90 src/og.png --out og.jpg
```

Обе команды — из штатной поставки макоси и Chrome, ставить нечего.
Промежуточный `src/og.png` после конвертации можно удалить.
Проверить результат: 1200×630, вес в районе 55–60 КБ.

## Локальный просмотр

Достаточно открыть `index.html` в браузере. Либо, чтобы пути вели себя
как на проде:

```bash
python3 -m http.server 8000
```

## Деплой

Хостинг — reg.ru, панель ispmanager. Сборки нет: файлы заливаются в корень
сайта по SFTP или через файловый менеджер ispmanager как есть.

Заливается: `index.html`, `styles.css`, `og.jpg`, `robots.txt`, `fonts/`.
Не заливается: `src/` и `README.md` — это исходники и документация, наружу
им незачем.

Домен `maximsorokin.com` уже привязан и резолвится на `2a00:f940:2:2:1:1:0:260`.
DNS не трогаем — на домене живёт почта `mail@maximsorokin.com`, MX-записи задевать нельзя.
GitHub Pages не используется, `CNAME` поэтому удалён.

После заливки проверить HTTPS и редиректы с `http://` и с `www.`
